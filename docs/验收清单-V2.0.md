# 验收清单 V2.0（开发自测 + 产品验收共用）

- **依据**: `docs/前端设计-V2.0.md`（CO-2026-11-18-01）
- **适用**: 三个 UI 任务（播放器 UI / 文章阅读导航 UI / 板书投屏 UI）+ 两个原型
- **用法**: 每条给"怎么点 / 期望什么"，打钩即通过；❌ 必须附截图或 msgId

---

## A. 口径红线（静态检查，`rg` 即可）

- [ ] `article` 相关代码中不存在 `play` / `pause` / `speed` / `volume` / `autoPlay`（`rg -i 'article.*(play|speed|volume|autoPlay)' src/` 0 命中）
- [ ] `cast.*` 处理器内无 `audio.` 调用
- [ ] 不存在"显示端出码"的实现残留：`rg -i 'deviceCode' src/display` 0 命中（显示端只认 `controlCode` 输入）
- [ ] 不存在 `fullScreen` 字段消费（`rg -i fullScreen src/` 0 命中）
- [ ] 不存在 `#/devices`、`#/pair` 路由与 `DeviceCard`/`Pair`/`MiniPlayerBar` 组件
- [ ] 场景切换处无 `audio.src=''`、`audio.load()`、`audio.remove()`
- [ ] 所有样式值来自 CSS 变量，显示端无硬编码字体/字号/背景色（`rg '#[0-9a-f]{6}' src/display/scenes` 仅允许兜底默认值 ≤3 处）

## B. 控制台（一屏）

### B1 登录与直达
- [ ] 登录成功后**直接**进主控台，中间无"选设备"页
- [ ] 访问 `/#/console/dev_001` 自动 `replace` 到 `/#/console`（不报错、不闪）
- [ ] 刷新主控台保持登录（JWT 7 天）与当前场景

### B2 控制码
- [ ] 顶栏常驻控制码（6 位数字；若启用 8 位 Base32 则 8 位），等宽字体、可一键复制
- [ ] 控制码旁显示**剩余有效期倒计时**（15 分钟起算），≤2 分钟转橙色
- [ ] 绑定成功后本码立即变「已使用」，点 ⟳ 才能给第二台屏幕出码（旧码同时作废）
- [ ] 倒计时归零 → 码变「已过期」，此时用该码输码一律提示「控制码已过期，请在控制台刷新后重新输入」
- [ ] 边缘限流生效：同一 IP 1 分钟内第 11 次输码 → 统一提示「控制码无效或已过期」（不泄露码是否存在）
- [ ] 点 `⟳` 刷新：码变化；**已连终端不掉线**；提示"新终端需用新码"
- [ ] n=0 时控制码升格为卡片并带引导语（"在教室屏幕输入此码"）

### B3 终端计数
- [ ] 显示"当前 N 个终端在线"，**不可点击**、不导航（无 `href`、无 `onClick`）
- [ ] 第 1 台接入 → 计数 1 并 toast「教室屏幕已连上」
- [ ] 全部掉线 → 计数 0 + 橙色 + 控制按钮 `disabled` + 文案「教室屏幕未连接」
- [ ] N 变化时 `aria-live="polite"` 播报

### B4 三场景互斥
- [ ] 三个 Tab（音乐/文章/板书）同一时刻只有一个激活
- [ ] 切换**无整页刷新、无白屏**（DevTools 网络面板无文档请求；Performance 录制无 >180ms 空白帧）
- [ ] 从音乐切走：音频**暂停**（不是停止），离开时显示"已暂停 · mm:ss"
- [ ] 切回音乐：从**同一位置**继续（误差 <1s），不从 0 开始
- [ ] 从文章切走再切回：滚动位置与 `anchorVerseSn` 完全一致，无重新拉取（Network 无新请求）
- [ ] 从板书切走再切回：草稿内容与 `castId` 保留，未过期时不重新预签名
- [ ] 双开两台显示端：切场景两台**同时**变化（fanout）

### B5 今日预选（音乐 + 文章）
- [ ] 进主控台即可见有序清单，空态为「今天还没排内容 ＋添加」
- [ ] 添加：点＋只打开选择器（搜索/浏览），选中后加入末尾并关闭
- [ ] 排序：上下移动/拖拽生效，顺序刷新后不丢（本地或服务端）
- [ ] 点条目 → 该场景激活并从该项开始（音乐出声 / 文章定位到该章）
- [ ] **使用中**（非编辑态）界面**没有**搜索框；搜索只在添加时出现
- [ ] 当前项高亮；"下一个"指向清单下一项；清单末尾时提示"已到清单末尾"
- [ ] 音乐自然播完 → 自动播放清单下一项并高亮移动

### B6 音乐控制
- [ ] 播放 → 拖进度 → 切音轨 → 暂停 → 继续，全链路 `ack` 正常
- [ ] 拖动时不被 5s 上报覆盖；松手 3s 内对齐；失败 toast「跳转未确认」
- [ ] 无伴奏曲目 `TrackSwitch` 置灰并带 title 说明

### B7 文章
- [ ] 点预选章 → 显示端定位到 `anchorVerseSn`；同章同锚点重复下发不滚动
- [ ] 翻屏：`下一屏` 滚一屏，章末停住并提示「已到章末」
- [ ] 章内临时字号与全局字号冲突时以临时为准，切章后清空

### B8 板书
- [ ] text / image / pdf 各投一次；PDF 走 R2 预签名
- [ ] 板书独占全屏（**不存在**"左侧窄栏 + 右侧板书"）
- [ ] 结束板书 → 场景回 Idle（不是回上一场景）；控制台无「音乐播放中」chip（该 UI 已删）

### B9 样式下发
- [ ] 改字体/字号/行高/对齐/背景/正文色 → 点「下发」→ 显示端**即时**变化（<300ms），**不刷新页面**
- [ ] 字号拉到 2.0：正文不溢出、不横向滚动；系统层提示条字号不变
- [ ] 样式只作用于内容层；控制台自身样式不受影响
- [ ] 显示端刷新/断电重启后仍是上次样式（`localStorage.cds.style`）
- [ ] `state.report.styleVersion` 落后时控制台自动重推一次
- [ ] 断网时下发 → 显示「样式可能未生效」，恢复连接后**自动**重推

## C. 显示端

### C1 输码态
- [ ] 无本地码时**只**显示输码框（6 位数字 / 8 位 Base32 按配置）+ 「确认」+ 右下角 12px「长按 3 秒重置」，无其他链接/按钮
- [ ] 输入框上方显示该码**剩余有效期**（如「剩余 12:40」）；过期码输不进去，给过期文案而不是"码错误"
- [ ] 过期文案 =「控制码已过期，请在控制台刷新后重新输入」；失效/撤销文案 =「控制码已失效，请重新输入」（两者不可混用）
- [ ] 支持数字键盘、自动跳格、整串粘贴、回车确认
- [ ] 码错 / 已撤销：错误**内联**在输入框下，不弹窗，可立即重输
- [ ] 长按 3 秒有环形进度反馈 → 清码并停留输码态（`?reset=1` 等效）

### C2 绑定 + 音频解锁（重点）
- [ ] 输码「确认」→ 绑定成功 → 进内容态；**控制台第一条 `player.play` 直接出声**（无第二次点击）
- [ ] 浏览器策略拦截时：内容态仍进入，系统层大字「点击屏幕任意位置启用音频」，触摸后恢复且控制台收到 `ack 4002` → toast
- [ ] 断网状态下输码：明确提示"网络不可用"，不白屏、不无限转圈

### C3 内容态（全被动）
- [ ] 屏幕上**没有**任何可点控件（无场景切换器、无设置、无按钮、无右键菜单）
- [ ] 鼠标悬停无 pointer 光标、无 tooltip 交互；Tab 键不聚焦任何元素
- [ ] 三个场景切换全部由控制台驱动；显示端无本地状态机入口

### C4 兜底回退（P0）
- [ ] 控制台点「全部解绑」/换控制台 → 显示端 3s 内回输码态并提示「控制码已失效，请重新输入」
- [ ] 码被判无效（`code.invalid`）→ 同上，且 `localStorage` 已清
- [ ] 断网 10s：保留最后一帧内容 + 黄条「与教室网络断开，正在重连…」，**不黑屏**
- [ ] 断网期间重启：先渲染 `cds.lastFrame`，连上后按 `state.report` 对齐
- [ ] 恢复网络后无需人工干预即回到正确场景

### C5 多终端
- [ ] 同一控制码在 2 台显示端同时输码 → 两台都绑上，控制台计数 2
- [ ] 一台断开 → 计数 1，另一台不受影响
- [ ] 超过上限（默认 4）再输码 → 明确拒绝并提示"终端数已达上限"

## D. 异常与降级

- [ ] 拔网线 10s：控制台降级轮询出现，指令仍响应（`delivered=polling`）
- [ ] 设备离线时点控制 → 按钮 `disabled` + 悬浮「设备离线」，不产生排队指令
- [ ] `ack` 3s 未回 → 同 `msgId` 重发一次 → 仍无 → toast 且 UI 回落
- [ ] 板书预签名 URL 过期 → 自动重签重发一次；两次失败给明确文案
- [ ] 两台控制台先后绑同一会话：后绑者接管，前者收到 `code.revoked` 提示（不静默掉线）

## E. 性能与体验

- [ ] 控制台首屏 Lighthouse ≥85（4G 覆盖）< 2s
- [ ] 显示端首包 <150KB gz、首屏 <1.5s
- [ ] 1080p 歌词滚动 / 经文翻屏 ≥55fps
- [ ] 场景切换 <180ms 无白屏（录屏逐帧核对一次）
- [ ] 样式下发生效 <300ms

## F. 原型（11-20 前交付物）

- [ ] `prototype/console.html`：单文件自包含（CSS/JS 内联、无外部 CDN），断网可打开
- [ ] 控制台原型包含：三场景切换、预选清单（可增删/排序/点用）、终端计数、控制码入口与刷新、样式下发表单
- [ ] `prototype/display.html`：两态齐全（输码 / 内容渲染），含样式下发效果演示、码失效回退、`?reset=1`
- [ ] 两页开在同一浏览器可互相驱动（BroadcastChannel 模拟下行），切场景/改样式显示端即时响应
