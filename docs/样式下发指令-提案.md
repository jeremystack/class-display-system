# 提案：`display.style` 样式下发指令（给开发，未改 mqtt.md）

- **提出**: 软件产品设计（2026-11-18）
- **背景**: V2.0 要求"字体/字号/排版/背景由控制台下发，收到即时生效不刷新"，但 `docs/mqtt.md` V2.2 **没有任何样式类指令**（仅有 `article.navigate.fontScale` 这一个章内字段）。按分工我不改 mqtt.md，这里给字段与语义，请开发并入 mqtt.md 下一版。
- **性质**: 新增一条下行指令 + `state.report` 两个字段；无 API 变更（可选 REST 持久化见 §5）。

---

## 1. 指令

```json
{
  "v": 1,
  "msgId": "m-31",
  "ts": 1763500000000,
  "type": "display.style",
  "payload": {
    "styleVersion": 7,
    "fontFamily": { "ui": "system-ui", "body": "songti" },
    "fontSizePx": 72,
    "lineHeight": 1.75,
    "charsPerLine": 12,
    "fg": "#f2f4f8",
    "fgMuted": "#b8c0cc",
    "accent": "#8ab4f8",
    "background": { "color": "#000000", "imageUrl": null, "fit": "cover", "dim": 0.25 },
    "align": "left",
    "letterSpacing": 0.02
  }
}
```

| 字段 | 类型 | 取值 | 说明 |
|------|------|------|------|
| `styleVersion` | int | 单调递增 | 幂等键：显示端 `<=` 已应用版本 → 直接 `ack ok` 不重写变量 |
| `fontFamily.ui` | enum | `system-ui` \| `sans` \| `serif` \| `hei` \| `song` \| `kai` | 白名单枚举，**不收任意字符串**（防注入 / 防本地无此字体） |
| `fontFamily.body` | enum | 同上 | 正文与经文用，可与 ui 不同 |
| `fontSizePx` | int | **24–120，步长 4，默认 72** | 内容层根字号，显示端**直写** `--cds-font-size`（px，不经 rem 乘法）；越界 `clamp(24,120)`、非 4 的倍数向下取整 |
| `lineHeight` | number | 1.2–2.2，步长 0.05 | 正文行高；**只改行高，段距恒 `1.1em`** |
| `charsPerLine` | int | **6–40，步长 1，默认 12** | **每行字数**（V2.1.10，`mqtt.md` V2.2.8 起为协议字段）。硬约束 `charsPerLine × fontSizePx ≤ 可用宽`（1920 扣 5vw×2＝1728px：24px→72 字、48→36、72→24、96→18、120→14）；显示端按上限 clamp，并在 `ack` 里回报实际生效值 |
| ~~`fontScale`~~ | — | **作废（V2.1.10）** | 与 `fontSizePx` 并存会把字号乘两次（72×1.15＝82.8px，且越出步长 4 的网格）。协议侧只保留「以 `fontSizePx` 为准、收到 `fontScale` 忽略并 warn」；`article.navigate.fontScale` 同步降级为「不实现」 |
| `lineHeight` | number | 1.2–2.2，步长 0.05 | 正文 |
| `fg` / `fgMuted` | string | `#rrggbb` | 正文 / 次级 |
| `accent` | string | `#rrggbb` | 当前歌词行、高亮经节 |
| `background.color` | string | `#rrggbb` | 底色 |
| `background.imageUrl` | string \| null | https | 背景图；建议只接受本站 `/assets/` 或 R2 预签名（≤10 分钟），**不接受任意外链** |
| `background.fit` | enum | `cover` \| `contain` | 默认 `cover` |
| `background.dim` | number | 0–0.8 | 背景图上压暗层，保证文字对比度 |
| `align` | enum | `left` \| `center` | 正文对齐 |
| `letterSpacing` | number | 0–0.1 | em |

## 2. 显示端处理

0. **三参任一变更**（`fontSizePx` / `lineHeight` / `charsPerLine`）→ 必须**重排并重发 `pageMap`**；旧 `pageCount`/`viewLines` 立即作废，不得跨样式复用（`mqtt.md` §4.6 同款约束）。分页按字符宽度切行（全角 1／半角 0.5）、整节下移装页，DOM 实测只作校验。

1. 校验：枚举越界 → 用默认值并 `ack {ok:false, code:4002, reason:"invalid_style_field"}`（**不整包拒绝**，其余字段照常生效，避免"因为一个颜色写错整屏回默认"）。
2. 应用：写 CSS 变量（`--cds-font-*`、`--cds-fg`、`--cds-bg` …），一次 `style` 属性写入 + 200ms transition，**不刷新、不重建内容 DOM**。
3. 持久化：`localStorage.cds.style = payload`，下次启动先套再连。
4. 上报：`state.report.payload.styleVersion = <已应用版本>`，便于控制台发现落后重推。
5. **`fontScale` 已作废**：不再有「章内倍率优先」这条路径；章内临时字号改走 `article.navigate.fontSizePx`（24–120/4/72），切章或新 `display.style` 到达时清空。

## 3. `state.report` 增补

```json
{
  "type": "state.report",
  "payload": {
    "online": true,
    "scene": "music",
    "nowPlaying": { "type": "music", "id": "f3f9…", "positionMs": 42500, "isPlaying": true, "volume": 50 },
    "viewing": null,
    "casting": null,
    "styleVersion": 7,
    "appVersion": "0.1.0"
  }
}
```

- **`scene` 必填**，`music|article|cast|idle`；
- `nowPlaying` / `viewing` / `casting` **至多一个非空**（互斥不变量 1，`null` 而非 `{}`）；
- `styleVersion` 必填。

## 4. 场景切换指令（同批，供参考）

```json
{ "type": "scene.set", "payload": { "scene": "article", "reason": "user_switch" } }
```

- 服务端保证顺序：旧场景资源先停（音乐 `pause` 并记位置），新场景再起；
- 显示端不自行推断，只按 `scene.set` 切可见性；`player.*` / `article.*` / `cast.*` 依旧驱动具体内容。

## 5. 可选 REST（若要做"换手机也保留样式"）

```
GET  /style            → { scope:"device|user", style:{…}, styleVersion:7 }
PUT  /style            { styleVersion, style }         // 服务端自增版本
```

产品这边 P0 只需 MQTT 下发 + 本地持久化；REST 持久化 P1（换设备/换手机才需要）。

## 6. 安全与运维注意

- 背景图只允许站内/预签名 URL，禁任意外链（防被换图/追踪）；
- `styleVersion` 必须服务端生成，禁止显示端自增（防多终端版本漂移）；
- 样式指令与内容指令**分开发**：`display.style` 不携带内容，避免一次改样式把场景也切了；
- 现场首屏兜底：显示端无网启动时用 `cds.style` 缓存，无缓存用内置默认（深底浅字、字体 `system-ui`、`fontSizePx 72`、`lineHeight 1.75`、`charsPerLine 12`）。
