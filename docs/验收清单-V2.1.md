## A. 口径红线（静态检查，`rg` 即可）

- [ ] `article` 相关代码中不存在 `play` / `pause` / `speed` / `volume` / `autoPlay`（`rg -i 'article.*(play|speed|volume|autoPlay)' src/` 0 命中）
- [ ] `cast.*` 处理器内无 `audio.` 调用
- [ ] 不存在"显示端出码"的实现残留：`rg -i 'deviceCode' src/display` 0 命中（显示端只认 `controlCode` 输入）
- [ ] 没有为"显示端倒计时"新增按码查状态的公开接口：`rg -i 'control-code/\{|/bind/\{' src/` 0 命中（`GET /control-code` 只允许返回当前会话自己的码）
- [ ] 不存在 `fullScreen` 字段消费（`rg -i fullScreen src/` 0 命中）
- [ ] 不存在 `#/devices`、`#/pair` 路由与 `DeviceCard`/`Pair`/`MiniPlayerBar` 组件
- [ ] 场景切换处无 `audio.src=''`、`audio.load()`、`audio.remove()`
- [ ] **（V2.1）显示端无音频**：`rg -i 'new Audio|AudioContext|<audio' src/display/` 0 命中；`rg -i 'audio' src/display/` 只允许调试字段
- [ ] **（V2.1.3）时基不含 epoch、不读墙钟**：`rg -i 'startedAtEpochMs' src/` **0 命中**（全仓，硬红线）；`rg -n 'Date\.now\(\)' src/display/player/` **0 命中**——`Date.now()` 不得出现在时基/播放路径、不得参与 `pos(t)`。**待机时钟**（`theme` 显示的教室时间）与日志/遥测**允许**用 `Date.now()`，但只能在 `Clock`/`logger` 内，且不得写回 `base`/`t0`。歌词位置只能用 `performance.now()` 差值计算。（V2.1.1 曾写「全仓 `Date.now()` 0 命中」，会误杀待机时钟，作废）
- [ ] **（V2.1.1）scene 与 audio 是独立字段**：`rg -i 'scene.*audio|audio.*scene' src/` 无"用一个字段表达两者"的写法（否则一投屏音乐就断）
- [ ] **（V2.1）音频锚点唯一**：`rg 'cds.audio.lease' src/` 只见于 `shared/audio/anchor.ts`；两处页面都通过该模块取 `<audio>`，不存在各自 `new Audio()`
- [ ] **（V2.1.6）分页不按行数**：`rg -i 'lines' src/` 中 `article.*` 无 `lines` 参数；`article.scroll` 形状为 `{direction, unit, steps}`，`unit` 只接受 `page`/`section`（缺 `unit` 视为 `page`）
- [ ] **（V2.1）页码不作状态**：`rg -i 'pageIndex' src/` 只出现在渲染与上报，未写入持久化结构（`localStorage` / API body）
- [ ] **（V2.1）「续」标记不入正文**：`rg '（续）' src/` 只出现在页脚标记组件，未拼接进 `verse.text`
- [ ] 所有样式值来自 CSS 变量，显示端无硬编码字体/字号/背景色（`rg '#[0-9a-f]{6}' src/display/scenes` 仅允许兜底默认值 ≤3 处）
