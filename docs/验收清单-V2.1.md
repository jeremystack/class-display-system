## A. 口径红线（静态检查，`rg` 即可）

- [ ] `article` 相关代码中不存在 `play` / `pause` / `speed` / `volume` / `autoPlay`（`rg -i 'article.*(play|speed|volume|autoPlay)' src/` 0 命中）
- [ ] `cast.*` 处理器内无 `audio.` 调用
- [ ] 不存在"显示端出码"的实现残留：`rg -i 'deviceCode' src/display` 0 命中（显示端只认 `controlCode` 输入）
- [ ] 没有为"显示端倒计时"新增按码查状态的公开接口：`rg -i 'control-code/\{|/bind/\{' src/` 0 命中（`GET /control-code` 只允许返回当前会话自己的码）
- [ ] 不存在 `fullScreen` 字段消费（`rg -i fullScreen src/` 0 命中）
- [ ] 不存在 `#/devices`、`#/pair` 路由与 `DeviceCard`/`Pair`/`MiniPlayerBar` 组件
- [ ] 场景切换处无 `audio.src=''`、`audio.load()`、`audio.remove()`
- [ ] **（V2.1）显示端无音频**：`rg -i 'new Audio|AudioContext|<audio' src/display/` 0 命中；`rg -i 'audio' src/display/` 只允许调试字段
- [ ] **（V2.1.3）时基不含 epoch、不读墙钟**：`rg -i 'startedAtEpochMs' src/` **0 命中**（全仓，硬红线）；`rg -n 'Date\.now\(\)' src/display/player/` **0 命中**——`Date.now()` 不得出现在时基/播放路径、不得参与 `pos(t)`。**待机时钟**（`theme` 显示的教室时间）与日志/遥测**允许**用 `Date.now()`，但只能在 `Clock`/`logger` 内，且不得写回 `base`/`t0`。歌词位置只能用 `performance.now()` 差值计算。（V2.1.1 曾写「全仓 `Date.now()` 0 命中」，会误杀待机时钟，作废）
- [ ] **（V2.1.1）scene 与 audio 是独立字段**：`rg -i 'scene.*audio|audio.*scene' src/` 无"用一个字段表达两者"的写法（否则一投屏音乐就断）
- [ ] **（V2.1）音频锚点唯一**：`rg 'cds.audio.lease' src/` 只见于 `shared/audio/anchor.ts`；两处页面都通过该模块取 `<audio>`，不存在各自 `new Audio()`
- [ ] **（V2.1.6）分页不按行数**：`rg -i 'lines' src/` 中 `article.*` 无 `lines` 参数；`article.scroll` 形状为 `{direction, unit, steps}`，`unit` 只接受 `page`/`section`（缺 `unit` 视为 `page`）
- [ ] **（V2.1）页码不作状态**：`rg -i 'pageIndex' src/` 只出现在渲染与上报，未写入持久化结构（`localStorage` / API body）
- [ ] **（V2.1）「续」标记不入正文**：`rg '（续）' src/` 只出现在页脚标记组件，未拼接进 `verse.text`
- [ ] 所有样式值来自 CSS 变量，显示端无硬编码字体/字号/背景色（`rg '#[0-9a-f]{6}' src/display/scenes` 仅允许兜底默认值 ≤3 处）

- [ ] **控制台每行上限用 `layout`、不写死 1728**：`c_max = min(24, floor(layout.availW ÷ layout.fontSizePx))`。**判据（两组，别混）**：① **1280 宽 + 显式 72px** ⇒ 上限 **16**（`1152÷72`，整除），滑块尝试 24 必须**当场**被拦到 16 并显示「上限 16 字」；② `1280×800` 默认档（派生 52px）⇒ **22**（见上一条 131px 裁行的判据）。**未收到过 `layout` 时**才回退 1728 并标注「估算」——写死 1728 会让 1280 屏多排 2 字＝144px 溢出被静默裁掉
- [ ] **不依赖浏览器自然折行**：每行渲染成一个 `white-space:nowrap` 块，行块数 == `ΣL[k]`；把 `fontFamily` 换成 fallback（或无衬线↔宋体）后 `totalLines`/`pageCount`/`viewLines` **不变**（同一组参数必须同一结果）。`rg -n 'nowrap' src/display/` 命中
- [ ] **可用宽取「正文块内容宽」（V2.1.12）**：`charsPerLine` 的 `W` 必须是 `.body.clientWidth − 左右 padding`。**判据**：1280×800 窗口下 `#content.clientWidth=1280` 但真可用 `1152`，`c` 必须得 **22**（不是 24）；若实现拿 `#content.clientWidth`，`c=24`、行宽 1248 > 1152，行尾被 `overflow:hidden` 静默裁掉（原型实测溢出 131px）。测法：逐行比对 `ln.scrollWidth ≤ body.clientWidth`，**非首行必须 0px 溢出**
- [ ] **宽高都不成 24 的那档要算对（V2.1.12 反例）**：**1640×1080**（`clientWidth=1476`、`clientHeight=902`、72px）→ `c=20`、`totalLines=11`、`pageCount=3`、逐屏 **5/4/2**。**不得**按「24 字/行」写成 9 行 2 屏；四档 24 字/行是 `W÷F` 恰好 ≥24 的结果，不是常数
- [ ] **（P1，已知缺陷，不判通过与否）节号不得吃掉首行宽度**：`.sn` 是行内元素时首行＝节号＋`c` 字，首行行尾被裁——实测 27px（1280×800）/49px（1920×1080）/98px（4K）。修法（悬挂进 5vw 留白 / 首行少 1 字）都会改动四档表，**待裁决**；本轮只记录，不当通过
- [ ] **混排按宽度切**：`他使我躺卧在青草地 Li 3:16，安歇。` 按全角 1／半角 0.5 计宽 **17**，`c=12` 下切 **2 行**（若按字符个数 19 会算成 2 行但断点不同——必须按累加宽度断，断点落在第 12 个宽度单位后）
- [ ] **派生值显示口径**：显示端页眉「第 1 / 2 屏 · **全篇 9 行**」（默认档）；控制台「每行 24 字 · 首屏 5 行 · 共 2 屏」；`totalLines`/`verseLineStart` **不上行**（`pageMap` 仍 7 字段，`rg -n 'totalLines' src/` 在序列化处 0 命中）
- [ ] **算术＝实测（≤1px）**：校验取每节 `offsetTop/offsetHeight` 与算术 `lineY/L×行高` 比对，误差 ≤1px 通过；>1px 必须告警（`modelWarn`）并保留算术结果，**不得静默按实测覆盖**（否则同一参数两种屏数）
- [ ] **某节自身超一屏**：把 `c` 调到 6 或字号 120 造出超屏节 → 节内分屏、页脚「（续）」/下页「（续上）」，正文不插字符，`totalLines` 不变
