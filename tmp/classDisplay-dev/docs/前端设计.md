# Class Display System - 前端架构

## 技术栈
- **框架**: Preact
- **语言**: TypeScript
- **样式**: Tailwind CSS
- **状态管理**: Zustand
- **HTTP 客户端**: TanStack Query
- **路由**: Wouter

## 项目结构

```
client/
├── src/
│   ├── App.tsx            # 主应用
│   ├── components/        # 组件库
│   │   ├── common/        # 通用组件
│   │   ├── music/         # 音乐播放器
│   │   ├── article/       # 文章阅读器
│   │   ├── board/         # 板书投屏
│   │   └── device/        # 设备管理
│   ├── hooks/             # 自定义 Hooks
│   ├── store/             # 状态管理
│   ├── services/          # API 服务
│   ├── utils/             # 工具函数
│   ├── types/             # TypeScript 类型
│   └── styles/            # 全局样式
├── public/
└── package.json
```

## 核心页面设计

### 1. 登录页
- 用户认证
- 权限验证

### 2. 控制台页面
- **顶部导航**: 班级切换、设备列表、日志
- **左侧**: 已连接设备列表
- **中间**: 操作区（音乐/文章/编排）
- **右侧**: 板书投屏、快捷键提示

### 3. 显示端页面
- **沉浸式显示**: 纯内容展示
- **悬浮控制**: 播放控制、分屏模式、关闭
- **状态指示**: 连接状态、同步状态

## 状态管理设计

### MusicStore
- 当前播放状态
- 曲目列表
- LRC 歌词同步

### ArticleStore
- 文章滚动位置
- 播放/暂停状态
- 章节切换

### BoardStore
- 板书内容
- 全屏/普通模式
- 图片上传

### DeviceStore
- 设备连接状态
- 在线设备列表
- 心跳监控

## 组件化设计

### 通用组件
- `Button` - 按钮组件
- `Modal` - 弹窗组件
- `Table` - 表格组件
- `Input` - 输入组件

### 业务组件
- `MusicPlayer` - 音乐播放器
- `ArticleReader` - 文章阅读器
- `BoardWriter` - 板书编辑器
- `DeviceList` - 设备列表

## 响应式设计
- 控制面板：1920x1080 优先
- 显示端：自适应各种分辨率
- 移动端：仅支持显示端查看
