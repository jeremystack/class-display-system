# Class Display System - 后端架构

## 技术选型
- **Runtime**: Cloudflare Workers
- **Framework**: Cloudflare Workers 原生 + Tauri
- **数据库**: Cloudflare SQLite
- **通信**: EMQX MQTT

## 项目结构

```
server/
├── src/
│   ├── index.ts           # 入口文件
│   ├── routes/            # API 路由
│   │   ├── auth.ts        # 认证路由
│   │   ├── classes.ts     # 班级管理
│   │   ├── devices.ts     # 设备管理
│   │   ├── events.ts      # 事件管理
│   │   └── board.ts       # 板书管理
│   ├── services/          # 业务逻辑层
│   │   ├── classService.ts
│   │   ├── deviceService.ts
│   │   ├── eventService.ts
│   │   └── mqttService.ts
│   ├── models/            # 数据模型
│   ├── db.ts              # 数据库连接
│   └── mqtt.ts            # MQTT 客户端
├── worker-configuration.d.ts
└── package.json
```

## 核心功能模块

### 1. MQTT 服务
- 连接 EMQX 订阅主题
- 接收设备状态上报
- 广播控制指令

### 2. 事件广播
- 音乐播放事件
- 文章滚动事件
- 板书投屏事件

### 3. 设备管理
- 设备注册与注销
- 心跳保活
- 状态同步

## 数据库表结构

### devices 表
```sql
CREATE TABLE devices (
    id TEXT PRIMARY KEY,
    class_id TEXT,
    name TEXT,
    device_type TEXT,
    online_status INTEGER DEFAULT 0,
    last_heartbeat TEXT,
    created_at TEXT DEFAULT (CURRENT_TIMESTAMP)
);
```

### classes 表
```sql
CREATE TABLE classes (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    created_at TEXT DEFAULT (CURRENT_TIMESTAMP),
    updated_at TEXT
);
```

### events 表
```sql
CREATE TABLE events (
    id TEXT PRIMARY KEY,
    class_id TEXT NOT NULL,
    type TEXT NOT NULL,  -- music, article, board
    data TEXT NOT NULL,  -- JSON
    created_at TEXT DEFAULT (CURRENT_TIMESTAMP)
);
```

### board 表
```sql
CREATE TABLE board (
    id TEXT PRIMARY KEY,
    content TEXT NOT NULL,
    type TEXT NOT NULL,  -- text, image
    created_at TEXT DEFAULT (CURRENT_TIMESTAMP)
);
```
