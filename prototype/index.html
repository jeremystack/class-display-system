控制台 · 一屏

打开控制台原型 →

顶栏控制码 + 终端在线数；音乐 / 文章 / 板书互斥切换；今日预选清单；样式下发表单。

 显示端 · 两态

打开显示端原型 →

输码态（含长按 3 秒重置）；内容态零控件；样式即时生效；码失效自动回输码页。
怎么演示（两个页面开在同一个浏览器/同一域名下即可互相驱动）
  1. 先开控制台，记下顶栏控制码（默认 482 913）。
  2. 再开显示端，输入该码 → 确认 → 进入内容态（这一步同时解锁音频）。
  3. 回控制台点「音乐 / 文章 / 板书」或点预选条目 → 显示端跟着变，无刷新。
  4. 控制台底部「显示样式」改字号/字体/背景 → 下发 → 显示端即时变化。
  5. 控制台点「全部解绑」→ 显示端回到输码页并提示「控制码已失效，请重新输入」。
原型不含构建产物与外部依赖（CSS/JS 全内联，断网可开）；真实联调以 docs/前端设计-V2.0.md 为准。
