1. 文章区只有导航、翻屏、字号、检索、书签 —— 没有朗读 / 播放 / 语速 / 音量。
2. 投屏不暂停音乐：点「开始投屏」后右侧出现「♪ 音乐播放中」，音乐继续走；关掉「全屏铺满」即配乐 + 板书。

5. 连接三态：点设备名旁的在线徽标 → 轮询中 / 离线，出现黄条 / 红条并禁用控制。
6. 全部交互为前端模拟，不连后端；曲库、经文为内置示例数据。

1. 因式分解法：化为两个一次因式的积等于 0。

3. 公式法：x = (-b ± √(b²-4ac)) / 2a
4. 例：x² - 5x + 6 = 0 → (x-2)(x-3) = 0 → x = 2 或 3
