打开单屏模式 →

一台电脑 + HDMI 复制：全屏内容 + 迷你控制条（点即播/即投/下一页/黑屏）。不需要输控制码。

 显示端 · 被动

打开显示端 →

输码态；待机主题两形态（大图 / 纯黑）；内容态零控件；无音频（歌词由控制页时基驱动）。
怎么演示（页面开在同一浏览器 / 同一域名下即可互相驱动）
  1. 控制台记下控制码（15 分钟、单次消费）→ 显示端输码 → 进待机（主题大图或黑屏）。
  2. 控制台点「待机 → 黑屏」→ 显示端变纯黑；再点回「主题大图」。
  3. 点预选里的曲目 → 即播（声音在控制台这台机器，显示端只跟着变歌词）。曲终不自动续播。
  4. 点经文 → 只是预览（屏幕上仍是待机）→ 点「开始投屏」才上屏 → 「结束投屏」回待机，再次投出从原位继续。
  5. 把字号从 72px 拉到 96px（或拖「行距」滑块）→ 显示端重排、页码总数变化、跨页处页脚出现「续」，正文不被插入字符；控制台「一屏 N 行」取显示端实测，不是估的。
  6. 新开 screen.html：单屏模式演示点条目即播/即投、迷你条 3s 淡出、黑屏、退出。
两条物理约束（不是 bug）：① 显控一体＝HDMI 复制，学生看得见这一屏（含控制条与按黑屏的动作），「黑屏」只保证内容不泄露；② 复制模式下无法同时显示 PPT——要放 PPT 就导出 PDF 走板书场景。
